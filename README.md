## O que está no arquivo

| | |
|---|---|
| **Contratos** | Adjudicações do Portal Base · desde 2012 |
| **Finanças** | Receitas, despesas e dívida municipal · 2012–2024 |
| **Transferências** | Transferências do Estado e do Município às freguesias |
| **Subsídios** | Apoios atribuídos a entidades do concelho |
| **Entidades** | Perfis de adjudicatários e beneficiários |
| **Freguesias** | Dados por junta de freguesia |

## Como funciona

Os dados são recolhidos de fontes oficiais — [base.gov.pt](https://base.gov.pt), [dados.gov.pt](https://dados.gov.pt) e documentos de prestação de contas — e disponibilizados de forma estruturada e pesquisável.
